# Голосовой модуль Автодневника

Файлы модели распознавания русской речи для приложения «Автодневник голосом».
Приложение скачивает их само — только на телефонах без распознавания речи Google
(например, Huawei и Honor без сервисов Google). Распознавание идёт прямо на телефоне, без интернета.

Здесь нет кода приложения — только модель.

## Модель
- **vosk-model-small-ru-0.22** — проект [Vosk](https://alphacephei.com/vosk/), Alpha Cephei Inc.
- Источник: https://alphacephei.com/vosk/models
- Лицензия: Apache License 2.0 (файл LICENSE, текст: https://www.apache.org/licenses/LICENSE-2.0).
- Архив модели не изменён — тот же файл, что на сайте авторов.

## Состав
- `vosk-model-small-ru-0.22.zip` — архив модели (~44 МБ). Телефон скачивает его и распаковывает у себя.
- `manifest.json` — размер и контрольные суммы архива (MD5, SHA-256) и список файлов внутри с размерами:
  приложение проверяет архив после скачивания и файлы после распаковки.
- Метка `v1` — неизменная версия, на которую ссылается приложение.
